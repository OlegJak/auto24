# auto24 — редизайн (прототип)

**🔗 Сайт: https://olegjak.github.io/auto24/** · [Русская версия](https://olegjak.github.io/auto24/index.html?lang=ru)

Концепт нового дизайна [auto24.ee](https://www.auto24.ee): светлая тема, оригинальный логотип и фирменные цвета, удобный поиск и страница объявления. Статический прототип на HTML, CSS и JavaScript, без сборки и зависимостей.

## Запуск

```bash
python3 -m http.server 5173
```

Затем откройте http://localhost:5173. Русская версия: http://localhost:5173/index.html?lang=ru (язык также переключается в шапке, ET / RU).

## Страницы

| Файл | Что это |
| --- | --- |
| `index.html` | Главная: логотипы порталов, рекламный блок, поиск с фильтрами и популярные марки, свежие объявления, аукционы, продажа авто, журнал |
| `otsing.html` | Поиск: полный фильтр как на auto24 (марка/модель до 3 шт., кузов, год, цена, платёж, мощность, пробег, топливо, КПП, привод, цвет, местонахождение, продавец, возраст объявления, аукцион, 248 пунктов оборудования) |
| `kuulutus.html?id=…` | Объявление: галерея, цена и оценка рынка, auto24 Liising, налоги, Ostuabi и vininfo, оборудование, похожие |
| `mark.html` | Пошаговый выбор: марка → модель/серия → поколение → объявления |

## Структура

```
assets/
  styles.css      дизайн-система и все стили
  app.js          шапка/подвал, карточки, фильтрация, лизинг, хлебные крошки
  data.js         39 реальных объявлений с auto24.ee (фото — с CDN auto24)
  catalog.js      справочники фильтра auto24, оборудование машин, налоги
  makes.js        модели и поколения 46 марок со страниц марок auto24
  i18n.js         русский перевод (термины фильтра — из русской версии auto24)
  home.js, search.js, listing.js, makes-page.js   логика страниц
  ad-banner.jpg   рекламный баннер
```

## Данные

- Объявления, фото, оборудование, налоги, модели и поколения взяты с auto24.ee для демонстрации. Имена частных продавцов не используются.
- Условные значения прототипа: время публикации, бейдж «Uus», две зачёркнутые цены, «рыночная цена», возможность обмена, общие счётчики объявлений.
- Логотипы марок — открытый набор [car-logos-dataset](https://github.com/filippofilip95/car-logos-dataset) через jsDelivr.
- Ставка в калькуляторе лизинга (8,5%) подобрана по примерам auto24 и не является официальной.
